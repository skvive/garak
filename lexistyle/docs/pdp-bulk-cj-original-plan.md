# 미생성 상품페이지 일괄 생성 기획 (CJ 원본 이미지 + 쿠팡 규칙 텍스트)

기준일: 2026-10-19. 상태: **조사·기획만, 미구현.** 수치는 로컬 DB 기준(운영 Neon은 착수 전 재집계).

## 1. 현황 (실측)

| 항목 | 값 |
|------|----|
| 노출 상품(삭제·더미 제외) | 774 |
| PDP 문서가 있는 상품 | 1 (나머지는 `resolveStorefrontPdp`가 **sample3-fallback** 템플릿 + 대표이미지 1장으로 렌더) |
| 미생성 | 773 (여성의류 그룹 99, 남성의류 그룹 38 포함) |
| **제외 후 대상** (여성의류 36·남성의류 12 leaf 제외) | **636** (이 중 아우터 그룹 49) |
| 최저 판매가 | $26.9 ≈ 37,361원 → **"3만원 이상" 필터는 전부 통과(변별력 없음)** |
| 대상 가격대(원) | <4만 74 · 4~6만 428 · 6~10만 91 · ≥10만 43 |
| 상품 이미지 3장 미만 | 대상 대부분(미생성 중 607/685) → 원본 이미지 확보가 핵심 |

- 판매가 하한이 (원가+20)×1.3 공식 때문에 약 $26이라 3만원 기준은 의미가 없다. **기준을 정해야 한다**(§6).
- 상품 단위 정본: `catalog_index`(공급처 상품) ↔ `products`(몰) ↔ `content_documents`(PDP). 분류 정본 `src/lib/catalog/lexi-cj-categories.ts`. `category_path`에는 최하위 leaf 하나만 들어 있어 의류 제외는 leaf→버킷 매핑으로 판정한다.
- 이미 있는 부품: CJ 상세 `fetchCjProductRaw`/`parseProductImages`, 임포트(sharp WebP·Blob), `generatePdpForCatalog`+`generatePdpText`(Gemini/DeepSeek/OpenAI), `renderPdp`, 게시 게이트 `getPdpGate`(`body.published.html`), 채널 투영 `projectForCoupang`. 없는 부품: **쿠팡 규칙을 담은 범용 상세 템플릿**(지금은 상품별 `build-*-coupang.ts` 수작업).

## 2. 대상 선정 (Stage 0)

대상 = 노출 상품 중 ① 게시된 PDP 없음(문서 없음·빈 HTML·정적 SAMPLE3 오버라이드 없음) ② leaf가 여성의류·남성의류 버킷 아님 ③ 가격 기준 충족 ④ CJ `externalId` 있음.
산출물: `tmp/pdp-bulk/queue.json`(상품·leaf·가격·상태). 읽기 전용 집계 스크립트로 반복 실행 가능.

## 3. 파이프라인

```
queue → ① CJ 원본 이미지 수집 → ② 이미지 정제·QA → ③ 쿠팡 규칙 텍스트·HTML 생성
      → ④ 규정 게이트 → ⑤ 배치 검수(HQ 미리보기) → ⑥ 게시(published) → ⑦ 라이브 검증
```

1. **이미지 수집**: CJ `product/query`의 `productImage`(배열 또는 JSON 문자열)와 변형(variant) 이미지 → 다운로드 → 해시 중복 제거 → 500px 미만 제외 → 최대 8장. 호출 간격 준수(CJ 한도 미확인, 첫 배치에서 측정).
2. **정제·QA**: 쿠팡 기준 DETAIL ≥500×500(권장 1000×1000, 부족하면 흰 패딩), WebP/JPG. **타사 로고·워터마크·중국어/연락처 텍스트 자동 탐지**(OCR 또는 비전 모델) → 걸리면 `needs-review`. 첫 장(대표)은 무로고만 허용.
3. **텍스트(쿠팡 규칙, `coupang-pdp-rules.md` 준수)**: 한국어 상품명(브랜드+품목+핵심속성, 과장·판촉어 금지), 서브카피·특징 3개, OPTION/SIZE GUIDE/DETAILS, 해외배송 고지 바, 배송·교환·반품(왕복 48,000/하자 24,000), `LEXI IS RPCOW.` 브랜드 노트, FAQ. 확인되지 않은 소재·성능 주장 금지, `CJ`·원가·내부 규칙 문자열 금지(정규식 검사). 의류용 AMBA 모델 섹션은 비의류에서 제외.
4. **카테고리 템플릿**: 홈리빙 / 반려 / 가방·슈즈 / 액세서리 / 테크 / 키즈 6종으로 섹션 구성·고시 항목을 분리(쿠팡 고시는 품목별로 다르며, 스킬의 "의류" 고정값은 의류 전용).
5. **규정 게이트**: KC 인증 대상(전기용품·LED·충전기, 어린이제품·완구·키즈 가방), 화장품·식품·건강기능, 반려 먹거리 등은 쿠팡 등록 대상에서 **분리**하고 몰 페이지만 생성하거나 보류.
6. **게시**: `PdpStructured` + `renderPdp` → `content_documents.body.published`에 저장하면 `resolveStorefrontPdp`가 자동 사용. 20~30개 단위 배치로 미리보기 승인 후 게시.
7. **검증**: 배치별 라이브 URL 샘플 확인, 금지 문자열·이미지 규격 자동 검사, 실패 건 재처리 큐.

## 4. 범위 구분
- **1단계(이 기획)**: 몰 상품페이지 생성(쿠팡 규칙 기반 텍스트, CJ 원본 이미지).
- **2단계(별도 승인)**: 같은 콘텐츠로 쿠팡 등록(`orders` 아닌 상품 등록 API, 승인 폴링, 중복명 검사). 이미지·고시·인증 요건이 더 엄격하다.

## 5. 리스크
- **이미지 정책 충돌**: 쿠팡 스킬 규칙 9는 "CJ 썸네일 히어로 금지·타사 로고 제거". 원본 그대로 쓰면 로고·워터마크·중국어 텍스트 반려 위험. QA 자동화 후에도 사람이 보는 표본 검수 필요.
- 저작권·상표: 원본 사진에 브랜드 로고가 있으면 게시 불가.
- LLM 환각: 속성은 CJ 데이터(`productProperty`, 변형)에 있는 값만 사용하도록 입력을 제한.
- 쿠팡 호출·CJ 호출·LLM 비용: 636건 × 텍스트 1회 + 이미지 최대 8장. 실제 비용·시간은 파일럿 20건으로 측정 후 산정.
- 로컬 DB와 운영 DB 상품 구성이 다를 수 있음 → 운영 기준으로 재집계 후 운영 반영은 승인 필요(문서·이미지가 커서 Neon 전송량 주의).

## 6. 결정이 필요한 것
1. **가격 기준**: 판매가 3만원은 전부 통과. 원가 기준(예: 원가 ≥ 3만원)이나 판매가 6만원 이상 우선 같은 다른 기준이 필요한가?
2. **아우터(49개)**: 의류 제외 범위에 포함할지.
3. **KC·화장품 등 규정 대상**: 몰 페이지만 만들지, 아예 제외할지.
4. **원본 이미지 정책**: 로고·텍스트 걸린 이미지는 제외(대표 이미지가 없으면 보류)로 둘지.
5. **파일럿**: 카테고리별 대표 5개씩 20건으로 시작할지.

## 7. 일정(안)
P0 대상 집계·큐 (0.5일) → P1 이미지 수집·QA (1일) → P2 텍스트·템플릿 6종 (1.5일) → P3 파일럿 20건 검수 → P4 배치 게시·검증. 소요는 착수 후 파일럿에서 재산정.
