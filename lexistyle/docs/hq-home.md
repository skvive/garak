# HQ 홈

`/hq` 는 파이프라인 전용 화면이 아니라 **오늘 손댈 일**을 모은 커맨드 센터다.

## 넣는 것 / 안 넣는 것

| 넣음 | 이유 |
|------|------|
| 검수·발주 대기 | 매출 운영이 파이프라인보다 급함 |
| PDP 리뷰 · 송출 실패 | 게시 막힘 |
| 분산원장 경보 | 유실·위변조는 홈에서 보여야 함 |
| 판매채널 상태 | 목업/정지/미연결을 숨기지 않음 |
| 파이프라인 숫자 | 소싱 진행은 2단으로 |

전체 메뉴 복제·큐 JSON·영문 CRAWL 라벨은 넣지 않는다. 상세는 각 보드.

## 레이아웃

1. 주의 KPI 6칸 (값>0이면 강조)
2. 바로가기 칩 (구매요청·판매채널·PDP·분산원장·정산·공급처)
3. 액션 큐 | 판매채널
4. 소싱 파이프라인 | 주문·원장
5. 최근 활동 (원장·송출·PDP·감사)
