# HQ 마이 컬렉션

관리자 계정(`ownerEmail`)마다 따로 갖는 **상품 작업함**. 플랫폼 커넥터가 아니라 카탈로그 상품페이지를 담는다.

## 상태
| 탭 | status | 역할 |
|----|--------|------|
| 컬렉션 | `bookmarked` | 작업 중인 상품 |
| 보관함 | `archived` | 나중에 쓸 상품 (숨김, 삭제 아님) |
| 휴지통 | `trash` | 제외. 복원만 |
| 담기 | — | 카탈로그에서 선택해 컬렉션에 넣기 |

## 분류
- **그룹**: 관리자가 붙이는 라벨 (뷰티, 여름컬렉션). 선택 상품에 일괄 지정.
- **카테고리**: 카탈로그 `categoryPath` 필터.

## 조작
- 목록/그리드. 기본 그리드(상품 썸네일).
- 체크 다중선택 → 그룹 지정 / 보관함 / 휴지통 / 복원.
- GET `/api/hq/bookmarks`가 카탈로그 제목·가격·썸네일을 붙인다.
- POST `{ catalogId | catalogIds, status, groupName }`.
