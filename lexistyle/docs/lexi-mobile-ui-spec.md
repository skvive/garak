# LEXI 모바일 커머스 UI 스펙 (Phase 0 전수분석)

> **출처**: Coupang iOS (Sep 2025) Mobbin 레퍼런스 269장 전수분석
> **목적**: 쿠팡의 **UX 패턴·정보구조·인터랙션·컴포넌트 체계**를 학습해 LEXI로 이식.
> **원칙**: 쿠팡 고유자산(로고·상표·마케팅 카피·아이콘 이미지)은 이식하지 않는다.
> 구조와 동작만 차용하고, 텍스트·아이콘·이미지·브랜드는 LEXI 자체 창작.

## 확정 방향 (사용자 결정)
- **브랜딩**: 하이브리드 — 구조는 밀집형(쿠팡식 정보밀도), 비주얼은 LEXI 에디토리얼.
  카테고리/검색/리스트는 밀집, 홈·PDP는 감성.
- **언어**: 한국어 우선 + 영문 병행 (국제 고객 전환 지원)
- **통화**: KRW 우선 표기 + USD 병행 (기존 역직구 관세계산 유지)

관련: Alta(Mobbin iOS Aug 2026) 기반 **아바타·가상피팅**은 커머스 IA와 별 트랙이다. 정본 `docs/lexi-mobile-alta-vto-plan.md`.

## 1. 화면 인벤토리
> 화면명 · 출처파일 · 진입경로 · 구성요소 · 상태

### S-001 스플래시 `[0]`
로고 중앙 정렬, 백색 배경, 무텍스트. → LEXI: 하트-인피니티 마크 페이드인.

### S-002 홈 — 비로그인 `[1]`
- **헤더**: 로고(좌) + `로그인` 아웃라인 버튼(우)
- **검색바**: 라운드 필드 + placeholder + 돋보기(우)
- **히어로 배너**: 풀블리드 이미지 캐러셀, 대형 타이포 오버레이, 하단 서브카피
- **퀵링크 그리드**: 5열 × 2행 = 10칸. 원형 컬러 아이콘 + 2줄 라벨. 일부 `NEW`/`+50%` 코너배지
- **로그인 유도 카드**: 문구 + full-width CTA `로그인 바로 가기 >`
- **섹션**: 아이콘+제목(`기간한정 파격 특가`) + 필터칩(`전체`/`골드박스`)
- **상품 캐러셀**: 가로 스크롤 카드
- **하단 탭바**: 5탭

### S-003 로그인 `[2]`
인앱 브라우저(도메인 노출 `login.coupang.com`, Cancel/AA/새로고침 바)
- 탭 2개: `이메일 로그인` / `휴대폰번호 로그인`(활성=파란 밑줄)
- 입력 필드(아이콘 프리픽스) + 체크박스 `간편 로그인 등록 ⓘ`
- Primary CTA `인증번호 발송` / Secondary 아웃라인 `회원가입`
- 프로모 배너(쿠폰 일러스트) + 하단 보조 링크

### S-004~006 회원가입 `[3][4][5]`
- **빈 상태 `[3]`**: 아이콘 프리픽스 필드 4개(아이디/비밀번호/이름/휴대폰) + 마스터 체크 `모두 확인하였으며 동의합니다` + 약관 리스트(`[필수]`/`[선택]` 태그 + chevron)
- **입력완료 `[4]`**: 유효 필드에 **초록 체크마크**, 헬퍼텍스트 `사용 가능한 비밀번호입니다`(초록), 선택항목 섹션 분리
- **약관 전체동의 `[5]`**: 마스터 체크 시 전체 하위 체크. **2단 중첩**(광고성 정보 수신 동의 → 이메일/SMS·SNS/앱푸시). Primary CTA `동의하고 가입하기` + 저작권 푸터

### S-007 홈 — 로그인 `[6][7]`

### S-008 홈 스크롤 — 상품 피드 `[8][9]`

### S-009 홈 스크롤 — 풀블리드 프로모 `[10]`

### S-011 홈 스크롤 — 버티컬 프로모 `[12][13]`

### S-021 PDP 전체 스크롤 (식품) `[37][38][39][40][41][42]` ★★★ Phase4 핵심 레퍼런스

- **리뷰 탭**: 별점평균+총건수 → 동영상리뷰 썸네일(재생시간) → 포토리뷰 그리드(+N더보기) →
  **속성만족도 바 차트**(`맛 만족도 89%`, `간편함 99%` — 라벨+프로그레스바+%) →
