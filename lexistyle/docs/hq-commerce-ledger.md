# HQ 분산원장 (커머스 무결성 감시)

커머스 원장(상품·주문·배너·정산·구매요청·소싱발주)이 **유실되거나 체인 밖에서 바뀌면** 경보를 띄운다.

운영 원칙: 중요한 기록만 append-only로 남기고, 사용자 요청 경로는 기록 enqueue만, 검증은 점검(스캔)에서 한다. 일반 장바구니 CRUD는 감시 대상이 아니다.

## 감시 대상

| 스트림 | 원장 | 기록 시점 |
|--------|------|-----------|
| 상품 | `products` | 관리자 생성·수정·삭제 |
| 주문 | `orders` | 주문 생성, 결제완료, 상태 변경 |
| 배너 | `banners` | 생성·삭제 |
| 정산·구매요청·소싱발주 | HQ 스냅샷 | 기존 상태 전이 감사와 동시에 |
| 리스팅 | HQ listings | 게시·승인 전이 |

## 점검

1. 스트림별 해시 체인 재계산 (앞 해시·일련번호·페이로드 다이제스트).
2. 현재 원장 스냅샷 다이제스트를 직전 점검과 비교.
3. 건수 감소, 체인 밖 변경, 해시 불일치를 경보로 남긴다.

`POST /api/hq/ledger { action: "scan" }` · cron `GET /api/cron/ledger-scan`.

화면: `/hq/ledger`.
