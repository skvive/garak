# HQ 판매채널

`/hq/channels` — 판매·콘텐츠 채널을 그리드로 보고, 카드를 누르면 운영 팝업이 열린다.

Export 큐 JSON·「큐 처리」버튼은 이 화면에서 제거했다. 송출 잡은 `/hq/pipeline/export`.

## 그리드

| 카드 | 역할 |
|------|------|
| LEXISTYLE | 자사몰. 팝업에 Cafe24 연결 |
| Coupang / Amazon AU / Shopify | 주문 인입·수수료·구매요청 |
| Instagram / TikTok / Naver / YouTube | 유입 콘텐츠. 핸들만 저장. 주문 원장 없음 |

## 운영 기능

- 상단 KPI: 판매/콘텐츠 수, 연결·준비, 목업, 주문, 검수대기
- 카드 상태: 실연동 / 준비 / 목업 / 미연결 / 정지
- 팝업: 일시정지(인입 스킵), 주문 인입, 구매요청 이동, 콘텐츠 핸들·메모
- 홈 「판매채널 헬스」는 같은 상태 소스

키 없으면 목업으로 표시한다. 실연동으로 위장하지 않는다.
