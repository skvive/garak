장바구니·주문·결제(토스)·리뷰·계정·알림·고객응대(csThreads)·관리자 골격·검색·support·배너

### 3.2 변형 (재활용)

| LEXI 기능 | 가락한상 전환 |
|---|---|
| shorts (상품 숏폰 자동 생성) | **"오늘의 시세·경매 숏폰"** 자동 생성 — 시세 데이터 + 상품 이미지로 매일 자동 제작 |

| sale (프로모션) | 경매가 폭락 상품 타임딜(라이브 커머스 연계) |
| trend (매거진) | 제철 수산물 가이드·살수율 확인법 에디토리얼 |
| community (UGC) | "오늘의 한 상" 인증샷 갤러리 |
| brands | **점포관(상인관)** — 점포별 별점·후기·시세 |

| categories | 수산/축산/청과/한 상/초장집 재설계 |

### 3.3 제거 (1차 오픈 범위 제외)

vto(가상피팅), amba(모델), looks(룩북), avatar, dreamina, sample1~3, ui-kit, coupang-results, hq, cafe24, Amazon AU/Shopee 스크립트, 다국어(i18n ko 고정)

### 3.4 신규 (가락한상 핵심 차별화)

1. **오늘의 시세판** `/prices` — 전일·오늘 시세, g당 가격, 점포별 비교 (사업계획서 핵심)
2. **살수율 등급 배지** — PDP에 A/B/C 등급 + 검수일 표시
3. **캠 캡처 인증 이미지** — 저울 계량 사진을 PDP·주문 완료 화면에 자동 노출
4. **배송 슬롯 선택** — 당일 3시간 퀵 / 새벽 / 일반. 주소 입력 시 반경 10km 배송권 자동 판정
5. **가락 복합 한 상** `/sets` — 수산+축산+청과+초장집 소스 묶음 주문(크로스셀 장바구니)
6. **합배송 배치 시스템** — TC 패키징 배치(시간대별) 기반 출고 관리
7. **초장집 예약** `/reservation` — 1층 회 구매 + 3층 좌석 예약·상차림비 선결제
8. **홈마카세 구독** `/subscription` — 월 1~2회 큐레이션 정기배송
9. **B2B 식자재 주문** — 사업자 인증 후 도매가 주문
10. **정산 대시보드** — 상인용 주간 정산 내역 조회 (계약 제6조 의무 이행)

## 7. 기술·운영 고려사항

1. **재고의 특수성**: 수산물은 당일 경매 수량 = 당일 재고. '재고 0 → 품절'이 아닌 '내일 경매 후 재입고' 예약 판매(경매 연동 알림) 설계.
2. **가격 변동성**: 상품 가격을 시세 기반으로 매일 갱신(관리자 시세 일괄 입력 → DX 대행 매니저 운영).
3. **콜드체인 표시**: PDP·주문 단계마다 5℃ 유지 뱃지 + 보냉백 동봉 안내.
4. **한글 SEO**: 상품명·카테고리를 "제철 대방어회", "살수율 A급 킹크랩" 등 검색 의도 키워드로 구성.
5. **PG**: 토스 유지(정기결제는 구독 단계에서 검토), 판매자 정산 계좌 연동.
6. **이미지**: 수산물 실사 위주, AI 이미지 생성은 보조(배경 정리)에 한정.
7. **계약 연계**: merchants 테이블의 수수료율·앵커 노출 기간은 별도약정서 값과 일치시켜 정산 자동화.

## 8. 문서 패키지와의 연계

| 문서 | 쇼핑몰 연계 지점 |
|---|---|
| 상인 설득 사이트 명세서 | 쇼핑몰은 소비자 앱, 설득 사이트는 상인 유치 — 동일 브랜드 토큰 사용 |
| 입점제안서 | '앵커 점포 메인 노출' → 홈 히어로 점포 노출 슬롯으로 구현 |
| 입점계약서 제4조 | 시세 제공 의무 → /merchant 시세 입력 폼 = 일일 시세 등록표 양식 |
| 입점계약서 제5조 | 캠 캡처·살수율 → camCaptures·fatRatioGrade |
| 입점계약서 제6조 | 정산 내역서 제공 → settlementsDetail + 주간 정산 PDF |
| 별도약정서 | 수수료율·TC 반입 시각 → merchants·tcBatches 설정값 |
