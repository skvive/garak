> **문서 구분**: 개발 착수 기준 문서 (v1.0)
> **작성일**: 2026-10-22
> **대상 시스템**: 가락시장 상인(중도매인) 대상 브랜드·입점 유치 웹사이트
> **참조 산출물**: 가락한상 사업계획서, 4대 핵심 상세 전략, 강남 오피스 타겟 팩 기획안, 시장·경쟁 리서치(2026-10 웹 조사, 부록 C)

## 1. 프로젝트 개요

### 1.1 목적과 포지셔닝

| 항목 | 내용 |
|---|---|
| 사이트 목적 | 가락시장 수산동·축산동·청과동 상인(중도매인)에게 '가락한상' 플랫폼의 가치를 설득하고 **입점 신청·상담 예약** 전환을 만드는 B2B 유치 사이트 |
| 타겟 사용자 | ① 1차: 가락시장 수산동 핵심 점포주(앵커 점포 후보, 1년차 목표 30개점) ② 2차: 축산동·청과동 점포주, 가락몰 3층 초장집 식당주 |
| 사용 시나리오 | ① 상인 자발 유입(오프라인 포스터 QR, SNS 콘텐츠 링크) ② 가락한상 매니저가 점포 순회 영업 시 **태블릿/스마트폰으로 대면 제시(현장 피칭 모드)** ③ 설명회 초청자 사전 확인 |
| 비(非)목표 | 소비자용 쇼핑몰·주문 앱은 본 사이트 범위에서 제외(추후 별도 Phase). 투자자용 IR 페이지도 제외 |

### 1.2 설득 목표와 핵심 KPI

| KPI | 목표치(런칭 3개월) | 측정 방법 |
|---|---|---|
| 입점 신청 폼 제출 | 월 15건 이상 | GA4 `apply_submit` 이벤트 |
| 상담 예약 | 월 10건 이상 | `consult_book` 이벤트 + 어드민 DB |
| 시뮬레이터 완료율 | 진입 대비 40% 이상 | `simulator_complete` 퍼널 |
| 신청 → 계약 전환율 | 40% 이상 | 어드민 파이프라인 |
| 세션 체류 시간 | 평균 2분 이상 | GA4 |
| 모바일 이탈률 | 50% 이하 | GA4 |

### 1.3 핵심 사용자 스토리

1. **상인 A(수산동 회 점포)**: "노량진처럼 온라인 시세 공개를 하고 싶었는데 방법을 몰랐다" → 사이트에서 벤치마크 사례와 DX 대행 서비스를 보고 3단계 절차로 신청한다.
2. **상인 B(청과동)**: "회 배달에 내 야채가 묶여 팔리면 좋겠다" → '가락 복합 한 상' 크로스셀 구조를 이해하고 축산·청과 파트너로 신청한다.
3. **매니저 C(현장 영업)**: 태블릿에서 '발표 모드'로 한 페이지 스크롤 피칭 → 시뮬레이터로 점포별 예상 수익 리포트를 즉석 생성해 카카오톡 공유 → 그 자리에서 신청 폼 작성을 대행한다.
4. **상인 D(초장집)**: 오프라인 식당 예약 연계 O2O 모델을 보고 식당 제휴를 문의한다.

## 2. 설득 구조 — IA 설계 원칙 (Persuasion Funnel)

상인의 의사결정 심리를 따라 정보 구조를 5단계 퍼널로 설계한다. **페이지 이동 경로가 곧 영업 스크립트**다.

| 단계 | 상인 심리 | 대응 섹션 | 핵심 콘텐츠 |
|---|---|---|---|
| 1. 공감 | "요즘 장사가 예전 같지 않다" | 홈 · 왜 가락한상 | 깜깜이 가격, 배송비 중복, 온라인 판로 부재 등 현실 문제 제기 |
| 2. 기회 | "왜 가락시장이어야 하지?" | 왜 가락한상 | 인어교주해적단 벤치마크 + 수산·축산·청과 통합 인프라 |
| 3. 이득 | "나한테 구체적으로 무슨 이득?" | 상인 혜택 | 수수료 제로, 앵커 혜택, DX 대행, 합배송, **매출 시뮬레이터** |
| 4. 신뢰 | "말만 그럴 듯하면 어떡하나?" | 신뢰 요소 + 실패 사례 반박 | 보증제(캠 캡처·살수율), 로드맵, 매니저 24시간 응답 약속, FAQ, **가락시장e몰 폐점 원인과 차별화 선제 설명(5.2)** |
| 5. 행동 | "그럼 뭘 하면 되지?" | 입점 절차 · 신청 | 3단계 온보딩 → 신청 폼 / 상담 예약 |

설계 규칙:
- 모든 페이지 하단은 다음 단계 CTA로 연결한다(상단 네비게이션에만 의존하지 않음).
- 설득 수치는 '수수료 0%', '배송비 건당 최대 3,000원 절감'처럼 구체 숫자로 표기한다.
- 40~60대 상인을 고려해 복잡한 관용구·외래어를 최소화하고, 버튼 문구는 동사형("입점 신청하기", "내 매출 계산하기")으로 통일한다.
- 리서치 근거(반론 대응): 가락시장 중도매인 85%가 온라인도매시장을 인지하지만, 37%는 '상품을 직접 확인할 수 없다'는 이유로 참여를 주저한다(한국청과 조사, 2024.8). 이 불안에 '캠 캡처 인증제·살수율 보증·TC 견학'으로 직접 응답하는 콘텐츠를 신뢰 단계에 필수 배치한다.
- 리서치 근거(선제 반박): 가락시장 공식 온라인몰 '가락시장e몰(가락24)'이 2022년 3월 폐점했다(농민신문). "또 온라인몰?"이라는 상인의 첫 반응을 예상하고, 실패 원인과 가락한상의 대응을 사이트에서 먼저 설명한다(5.2).

## 3. 권장 기술 스택

| 계층 | 선정 | 사유 |
|---|---|---|
| 프레임워크 | Next.js 14(App Router) + TypeScript | SEO(정적 생성)와 폼 API(Route Handlers) 단일화 |
| 스타일링 | Tailwind CSS + 디자인 토큰 | 모바일 퍼스트 반응형, 브랜드 색 일관성 |
| 데이터/백엔드 | Supabase(PostgreSQL) 또는 경량 Node API | 신청·상담 데이터 저장, 어드민 조회 |
| 지도 | 카카오맵 API | 가락시장 위치·배송권(반경 10km) 시각화 |
| 애널리틱스 | GA4 + 이벤트 계층 | 전환 퍼널 측정 |
| 배포 | Vercel | 프리뷰 배포로 영업팀 리뷰, 한국 엣지 리전 |
| 폼 보호 | Honeypot + rate limit (+ reCAPTCHA 선택) | 스팸 신청 차단 |

> 검수·현장 테스트 편의를 위해 1차 산출물은 의존성 0의 순수 HTML/CSS/JS 프로토타입(단일 파일 배포본 포함)으로 제공하고, 확정 후 위 스택으로 이식한다.

**성능 기준**
- LCP ≤ 2.5초, CLS ≤ 0.1, Lighthouse 성능 ≥ 90 (시장 현장 데이터 환경 고려)
- 이미지: WebP/AVIF + lazy loading, 히어로 배너는 200KB 미만
- 폰트: 웹폰트 2종 이내, 한글 서브셋 적용, `font-display: swap`

## 5. 페이지별 상세 명세

### 5.1 홈 `/`

**목적**: 5분 이내 상인 설득. 영업 매니저가 태블릿으로 상하 스크롤만 하면 피칭이 끝나는 '발표 모드' 겸용.

1. **히어로(첫 화면)**
   - 카피(안): "가락시장의 신선함, 이제 온라인이 팔아드립니다" + 슬로건 "가락시장의 신선함을 집 앞까지, 식탁 위 완벽한 수산 한 상"
   - 배경: 가락시장·수산물 고해상 이미지 + 브랜드 컬러 오버레이
   - CTA 2개: [내 매출 계산하기] → `#simulator`, [입점 신청하기] → `/apply`
   - 하단 수치 스트립: "초기 3~6개월 수수료 0%" · "반경 10km 당일 배송" · "1년차 30개점 목표" · "앵커 점포 선착순 5곳"
2. **문제 제기 섹션**: 깜깜이 가격 · 배송비 중복 · 앱 정산/리뷰 관리 부담 — 상인이 공감하는 문제를 카드 3~4개로 제시.
3. **기회 섹션**: 인어교주해적단 성공 요인 3가지 + 가락시장만의 차별점(수산+축산+청과 통합) 요약.
4. **혜택 요약 섹션**: 5.3의 혜택 카드 6종을 2행 그리드로 축약 노출.
5. **시뮬레이터 유도 배너**: "우리 점포는 얼마나 더 벌 수 있을까? 1분 계산" + CTA.
6. **절차 요약**: 3단계 입점 절차 축약 + 최종 CTA.
7. **푸터**: 브랜드 정보, 개인정보처리방침, FAQ 링크, 매니저 직통 연락처.

### 5.2 왜 가락한상인가 `/why`

1. **시장 현황·문제점**
   - 깜깜이 가격(시세 비공개로 인한 소비자 불신), 점포별 개별 배송비 중복, 소비자는 회만 원하지 않음(야채·고기·디저트까지 원함), 초장집 주말 대기 문제 — 표·아이콘 병행 표현.
2. **벤치마크: 인어교주해적단(더적중) 사례**
   - 성공 요인 3가지: 시세 투명성 → 소비자 신뢰 확보 / 점포 DB화(평점·후기·크기별 정량가) / 자체 B2B 유통망으로 마진 개선.
   - 전환 장치: "이 모델을 가락시장 인프라에 얹으면?" 질문형 섹션 타이틀.
3. **가락시장만의 기회**
   - 노량진 대비 비교표: 수산 특화 vs **수산·축산·청과 종합 도매시장**.
   - '가락 복합 한 상' 개념도: 수산 메인 + 축산 서브(매운탕용 차돌박이·육회) + 청과 사이드(손질 야채·쌈·과일) + 초장집 패키지(막장·콘치즈) — 일러스트 다이어그램.
   - 강남·서초·송파·강동·위례 반경 10km 배송권 지도(카카오맵).

4. **왜 이번에는 성공하는가 — 가락시장e몰(가락24) 폐점 교훈**

가락시장 공식 온라인몰 '가락시장e몰'은 2015년 개장 후 7년 만인 2022년 3월 운영을 종료했다. 상인이 가장 먼저 던질 질문("또 온라인몰?")에 대한 답을 이 섹션이 먼저 제공한다.

| 가락시장e몰 실패 원인 (2022.3 폐점) | 가락한상의 대응 |
|---|---|
| 자체몰 트래픽 확보 실패 — 매출 80~90%가 제휴 대형몰에 의존 | 유튜브·쇼츠 콘텐츠 커머스로 트래픽 자체 조달 + 자체 앱 독자 고객층 |
| 쿠팡·네이버와의 B2C 정면 경쟁 | '가락 복합 한 상'(수산+축산+청과)과 반경 10km 3시간 배송이라는 대형몰이 못 하는 틈새 공략 |
| 물류 시스템 미비 (전문가 지적) | 가락몰 내 TC 공동 패키징 + 합배송 + 보냉 표준화(5℃ 이하) |
| 상품 감정·신뢰 문제 | 캠 캡처 인증제, 살수율 A/B급 일일 공지, 미달 시 100% 환불 |
| 공공 운영의 마케팅·속도 한계 | 민간 콘텐츠 커머스 + 퀵커머스 실행력 |

> 전문가 조언 반영: "도매시장 온라인몰은 B2C보다 B2B로 가야 한다"(상명대 양석준 교수, 농민신문 2022.3) — 가락한상은 B2C(한 상 배송)와 B2B(식자재 공급)를 Phase 1부터 병행한다.

### 5.3 상인 혜택 `/benefits`

혜택 카드 6종 — 각 카드는 [자세히] 클릭 시 인라인 확장(모달 지양).

| # | 혜택 | 핵심 내용 |
|---|---|---|
| 1 | 수수료 제로 프로모션 | 초기 3~6개월 중개 수수료 면제, 정착 후 5~10%. 기존 플랫폼 대비 비교표 제시 |
| 2 | 앵커 점포 프로그램 | 선착순 5곳 — 앱 메인 화면 노출 보장, 전용 매니저, 마케팅 지원. "초대된 점포" 스카우트 프레임 |
| 3 | DX 대행 서비스 | 매니저 순회 — 당일 시세 대리 입력, 리뷰 답글 대행, 불만 고객 응대, 정산 확인 지원 |
| 4 | 합배송·풀필먼트 | 가락몰 내 공동 패키징(TC)으로 배송비 중복 제거. 점포는 상품 준비만 하면 됨 |
| 5 | 신뢰 보증제 | 캠 캡처 인증제(저울 무게 사진 고객 앱 자동 전송), 살수율 A/B급 일일 샘플링 공지, 미달 시 100% 환불 — 상인도 분쟁에서 보호 |
| 6 | 콘텐츠 마케팅 | 유튜브/쇼츠 정보성 콘텐츠로 점포 노출, 강남권 직장인 타겟팅 광고 |

- **수수료 비교표**: 기존 배달/중개 플랫폼 수수료 vs 가락한상 초기 0% → 정착 후 5~10%. 월 매출별 절감액을 표와 막대로 시각화.
- **매출 시뮬레이터** 섹션은 5.4로 분리.

### 5.4 매출 시뮬레이터 `/benefits#simulator`

**목적**: 점포별 '나만의 예상 수익 리포트' 즉석 생성. 현장 영업의 결정적 도구.

**입력 필드**

| 입력 | 형식 | 기본값 |
|---|---|---|
| 점포명 | 텍스트 | — |
| 업종 | 라디오(수산/축산/청과) | 수산 |
| 월 매출 | 슬라이더(100만~1억, 100만 단위) | 3,000만원 |
| 평균 객단가 | 슬라이더(3만~50만) | 15만원 |
| 복합 한 상(크로스셀) 참여 | 토글 | 참여 |
| 합배송 이용 | 토글 | 이용 |
| 수수료 단계 | 초기(0%) / 정착(5~10%) | 초기 |

**출력**
- 반경 10km 수요 기반 **예상 월 추가 주문 수**(침투율 가정 공개)
- 예상 월 매출 증분 / 수수료 절감액(프로모션 기간) / 배송비 절감액(합배송) / **예상 순증익**
- '계산 방식' 접이식 패널 — 공식을 투명 공개(신뢰 확보)
- **리포트 공유 버튼**: 이미지/PDF 다운로드 + 카카오톡 공유(상인이 점포에서 다시 확인 가능)

**계산 공식(예시)**
```
추가 주문/월 = 권역 잠재 주문 수(가정치) × 침투율(초기 1% / 성숙 3%)
             × 점포 지수(크로스셀 참여 ×1.3, 합배송 ×1.2)
추가 매출 = 추가 주문/월 × 평균 객단가
수수료 절감 = 추가 매출 × (기존 플랫폼 10% − 가락한상 수수료)
배송비 절감 = 추가 주문/월 × 합배송 분담 차액(건당 약 3,000원)
예상 순증익 = 추가 매출 − 가락한상 수수료 − 배송 분담 + 절감액
```
> 필수: "위 수치는 마케팅 가정 기반 예측치이며 계약상 보장 수치가 아닙니다" 각주 표시(신뢰 보호).

### 5.5 서비스 미리보기 `/preview`

상인이 '내 상품이 소비자에게 어떻게 보이는지' 확인하는 데모 페이지.

1. **소비자 주문 플로우 미니 데모**: 시세 조회 → 점포 선택 → 정량 주문(g당 가격, 캠 캡처 인증) → 당일 3시간 배송 선택 — 정적 스크린샷 + 화살표 스토리보드.
2. **가락 복합 한 상**: 수산+축산+청과가 한 장바구니로 묶이는 크로스셀 시각화.
3. **초장집 O2O**: [1층 회 구매 + 3층 식당 좌석 예약·상차림비 선결제] 프리패스 동선.
4. 상단 문구: "소비자용 앱은 준비 중입니다. 지금 입점하면 오픈 전 시세·상품 데이터 입력 우선권을 드립니다" (희소성 메시지).

3단계 온보딩 타임라인:

| 단계 | 시점 | 내용 | 필요 서류/준비물 |

| 1. 신청·상담 | Day 0 | 온라인 신청 → 24시간 내 전담 매니저 배정 | 사업자등록증(선택) |
| 2. 점검·계약 | 1주 내 | 점포 방문, 품목·시세 등록, 계약(해지 조건 명시) | 사업자등록증, 통장 사본 |

### 5.7 입점 신청 `/apply` (핵심 전환 페이지)

페이지 이동 없는 3단계 스테퍼 폼:

| 단계 | 필드 | 비고 |
|---|---|---|
| 1. 점포 정보 | 점포명*, 구역*(수산동/축산동/청과동/기타), 점포 위치(동·호), 대표자명*, 휴대폰*, 사업자등록번호(선택) | 휴대폰 형식 검증, 임시 저장(draft) |
| 2. 참여 형태 | 앵커 점포 지원 여부, 주력 품목(다중 선택), 복합 한 상 참여 의향, 합배송 동의, 상담 희망 방식 | 앵커 지원 시 "선착순 심사" 안내 |

규칙: 단계별 유효성 검증, 제출 후 어드민 파이프라인 자동 등록 + 담당 매니저 알림(카카오톡/이메일).

### 5.8 상담 예약 `/contact`

- 상담 유형: 현장 방문 / 전화 / 가락몰 내 미팅.
- 날짜·시간 슬롯 선택(매니저 순회 일정 기반, 불가 슬롯 비활성화).
- 예약 확정 시 알림톡 안내, 예약 1일 전 리마인드.

### 5.9 FAQ `/faq`

카테고리 아코디언: ① 수수료·정산 ② 배송·물류 ③ 품질 보증·분쟁 ④ DX 대행 ⑤ 계약·해지

예시 항목:
- "수수료 0%는 언제까지인가요?"
- "합배송을 쓰면 내 포장 시간이 늘지 않나요?"
- "살수율 미달 환불은 누가 부담하나요?"
- "중도 탈퇴하면 불이익이 있나요?"
- "예전 가락시장 온라인몰(가락24)도 문 닫지 않았나요?" → 실패 원인 5가지와 가락한상의 다른 점을 표로 안내(5.2 연결)
- "상품을 직접 보지 못한 손님이 불만을 제기하면 어쩌죠?" → 캠 캡처 인증제·살수율 보증으로 선제 차단, DX 매니저가 불만 응대 대행
- "이미 모두가락 같은 공공몰이 있는데 왜 또 하나요?" → 공공몰의 마케팅·속도 한계 대비 콘텐츠 커머스·퀵배송 차별점
- "농산물 온라인도매시장(2023년 출범)과는 뭐가 다른가요?" → B2B 도매 거래 vs B2C 당일 직배송 틈새 구분

### 5.10 어드민 `/admin` (로그인)

- **신청 파이프라인 칸반**: 신규 → 연락 시도 → 상담 → 계약 → 입점 완료 (드래그 상태 이동, 상태별 색상 뱃지)
- **상담 일정 캘린더**, **매니저별 담당 건수**, **전환 퍼널 통계**(신청→계약율)
- **신청 상세 뷰**: 점포 정보, 시뮬레이터 리포트 이력, 통화 메모
- 권한: 매니저/관리자 2단계, 이메일 + OTP 로그인

## 11. 수용 기준 (Acceptance Criteria)

1. 시뮬레이터는 입력 변경 시 300ms 이내 재계산, 리포트 다운로드·공유가 정상 동작한다.
2. 신청 폼은 네트워크 단절 시에도 draft가 보존되고, 중복 제출이 차단된다.
3. 모바일(360px)~태블릿(1024px) 전 구간 UI 깨짐이 없고 Lighthouse 성능 ≥ 90이다.
4. 어드민에서 신청 상태 전환 시 담당 매니저에게 알림이 발송된다.
5. 모든 설득 수치(수수료·배송비 등)는 사업계획서 수치와 일치하고, 시뮬레이터 결과에는 '예측치' 각주가 표시된다.

## 부록 D. 입점제안서 1페이지 초안 (상인 대면 제시용)

> 사이트 `/apply` 페이지와 시뮬레이터 리포트에 동일 수치를 사용해 통일성 유지. A4 1매 인쇄·카카오톡 공유 겸용.

**[가락한상] 입점 제안서 — 점포명님께**

한 줄 제안: **"가락시장 점포의 매출을 온라인이 늘려드립니다. 초기 6개월 수수료 0원."**

**1. 우리가 드리는 것**
- **새 매출**: 반경 10km(강남·서초·송파·강동·위례) 당일 배송 고객 — 직장인 회식·홈파티 수요 직결
- **수수료 0원**: 입점 후 6개월 중개 수수료 면제, 이후에도 5~10%(기존 플랫폼 대비 절반 수준)
- **손 안 대는 운영**: 당일 시세 입력·리뷰 답글·불만 응대·정산 확인까지 전담 매니저가 대행
- **배송비 절감**: 가락몰 내 공동 패키징(TC) 합배송으로 점포별 중복 배송비 제거

**2. 점포에 부탁드리는 것 (3가지)**
- 품질 약속: 캠 캡처 인증제 협조(저울 무게 사진 촬영), 살수율 기준 준수
- 당일 시세: 매일 아침 시세 한 줄 통보(전담 매니저가 대리 입력도 가능)
- 합배송: 지정 시간에 패키징 구역으로 상품 이동

**3. 예상 효과 (매출 시뮬레이터 기준)**
- 월 매출 3,000만원 점포, 크로스셀·합배송 참여 시 예상 월 매출 증분 약 OO원 + 배송비 절감 약 OO원
- (시뮬레이터 입력값에 따라 자동 생성되는 수치 삽입)

**4. 진행 절차**
1단계 신청·상담(24시간 내 매니저 연락) → 2단계 점검·계약(1주 내, 해지 조건 명시) → 3단계 오픈·지원(2주 내 첫 주문)
