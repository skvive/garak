## 2. 핵심 UI 패턴 (리서치 기반)

1. **오늘의 시세 티커** — 홈 히어로 직하단 무한 스크롤 마퀴. "대방어 55,000원 · 킹크랩(A급) 149,000원 ▼" — 인어교주해적단의 시세 투명성 계승, 매일 바뀌는 살아있는 홈.
2. **당일배송 마감 카운트다운** — "오후 3시 주문 마감까지 02:14:33 · 저녁 6시 전 도착". 결제 피크(목/금/토 17~21시, PickAround 데이터)를 노린 타임 커머스 장치.
3. **신선도 뱃지 3종** — `제철 NOW`(kelp 그린) / `당일경매`(오션 블루) / `시세 ▼20%`(코랄) — 상품 카드 우상단 계층화.
4. **사회적 증거** — "이번 주 300+명 구매" 카드 하단 라인 (구매 신호 = 신뢰 가속).
5. **양의 모호성 해소** — 모든 상품명·카드에 g/kg 단위 필수 표기 (이탈 요인 31% 대응).
6. **히어로 오션 그라디언트** — 바다 이미지 위 딥오션→투명 스크림 (웅진수산 사례의 '시원함' 계승).
